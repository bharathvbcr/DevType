Why DevType?

⚡

Instant Keyword Expansion

Low-latency swallowing ring buffer that replaces typed abbreviations instantly in any app via Accessibility APIs.

🎙️

Smart Voice Dictation

Push-to-talk speech-to-text with self-correction resolution, filler stripping, and four selectable recognizers (Apple Speech, Local AI, Local Whisper, and Gemini).

🤖

100% On-Device AI

Powered by Apple Foundation Models (macOS 26+). Proofread, rewrite, and condense text offline with zero API keys.

📝

Local Markdown & Text Tools

Instant case conversion, formatting, and offline Markdown stripping that runs locally on all macOS versions without an AI model.

🔍

Hybrid Command Palette

Press ⌘/ to search snippets, run AI transforms, insert date calculations, or access pasteboard history instantly.

🛡️

Fail-Closed Privacy

Automatically pauses expansion in password fields, Secure Event Input locks, IME composition, or muted apps.

🔒

Encrypted Secret Snippets

Store passwords AES-GCM-encrypted behind Touch ID. Secure Input changes the menu bar to Copy Secret. Choose a secret and paste with ⌘V; the concealed clipboard clears automatically.
