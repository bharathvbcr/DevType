A custom instruction runs on your selection. Check the result for changes to meaning or facts.

Choose how each action delivers.

Preferences → AI lets you choose direct replacement or a diff preview for individual actions. Proofread and Remove Markdown default to direct replacement; the other writing actions default to preview. Use preview when you want to compare the result before replacing your text.

Change your mind mid-draft.

Switch the tone, pick another action, or press Retry while a preview is still generating. DevType stops the earlier request and runs the new one, so the preview does not go blank. A blank result is shown as a failure rather than offered as a replacement, so your selection is never overwritten with nothing.

When macOS asks the model to wait.

Under heavy load, usually low memory, the system can defer an on-device request. DevType says so plainly and suggests quitting apps you are not using before you try again. Nothing is wrong with your prompt or the model.

Model-based actions need macOS 26+, Apple Intelligence, and a ready model. Remove Markdown is a deterministic tool and works without an AI model on macOS 14+.

Decide what Backspace means.

By default, Backspace can undo a recent snippet expansion. Switch off Undo expansion with Backspace in General preferences to use ordinary deletion instead. The choice takes effect immediately and persists across launches. Native ⌘Z and Undo last AI are separate controls.

Read the privacy details ↗

Choose where dictation runs.

Apple recognition stays on-device. Local servers receive data over loopback. Gemini sends audio to Google only with your API key and separate consent. Model setup can require downloads; recovery recordings are saved locally.

Keep secrets separate.

A dedicated Secrets manager, encrypted values, and deliberate copy-and-paste. No typed password triggers. Clipboard copies clear after 90 seconds if DevType still owns them; clipboard managers may retain copies.

Keep control of the target.

Expansion pauses during secure input and in muted apps. Delivery rechecks the target before changing text. You can turn Backspace expansion undo off whenever you prefer.

When the moment changes

Your text has a destination.

A shortcut can finish after your attention has moved. DevType checks the target again before delayed text changes, and can cancel an expansion when the original context no longer matches.

  1. Stay in the intended field

    Let the expansion finish before switching apps or moving the cursor. A changed target can cancel pending work; return to the field before trying again.

  2. Respect a paused session

    Secure Input and muted apps pause expansion. If a trigger stays as ordinary text, check those states as well as the engine’s pause setting.

  3. Inspect an uncertain paste

    “Posted, unverified” means a paste was sent but its receipt was not confirmed. Check the document before retrying so you do not insert the same text twice.

When an app is stubborn

Honest about
what happened.

Editors and system services do not always cooperate. DevType checks first, adapts where it can do so safely, and names the cause instead of guessing.

ADAPTS

Made for editors that bend the rules.

Cursor and VS Code can swallow a synthetic paste. For those editors DevType types the expansion as Unicode keystrokes instead; terminals and other apps keep clipboard paste. Where an element only reports a rendered view of its text, a trigger DevType typed itself still erases on a best-effort basis; real text fields keep the strict check.

EXPLAINS

A reason,
not a shrug.

A refused expansion carries a specific cause, so Permission Recovery points at the real fix and does not blame Accessibility when it is already granted. “Restart Engine” appears only when a restart could change the outcome, and a safe refusal is never presented as a broken engine.

REMEMBERS

A place for what
you missed.

Recent Activity lists warnings and events from the menu bar, each with a suggested next step: fix permissions, open the manager, review a kept dictation, or copy diagnostics. Return runs the action, Delete removes an entry, and clearing history never touches snippets, secrets, or settings.

Diagnostics that do not read over your shoulder.

Reports describe triggers and selections by shape, such as length and counts, rather than quoting your text. Error logs record the chain of underlying causes, and fingerprint non-system domains so paths and request contents stay out. Include a diagnostic report when you ask for help.

A few things to know.

Does everything need Apple Intelligence?

No. Snippets, palette utilities, Secrets, and deterministic text tools work on macOS 14+. Foundation Models actions need macOS 26+, a compatible Mac, Apple Intelligence enabled, and a ready system model. Voice engines have their own requirements.

Can I use my existing snippet library?

Import TextExpander settings bundles or Espanso YAML from the app. Export snippets as DevType JSON, Espanso YAML or a match folder, or CSV. Secret values are stored separately and are not part of snippet exports.

Will it work in every text field?

Editors expose text and selection differently. DevType checks the target and can refuse an unsafe or unverifiable replacement. Password fields and muted apps pause expansion. Check the destination before retrying a paste reported as unverified.

Is it free?

DevType is free and MIT-licensed. Optional services you configure yourself, such as Gemini, may have their own costs. You can use snippets and local text tools without a cloud account.

Can I change the shortcuts or pause expansion?

Yes. Preferences → Hotkeys lets you rebind the palette, AI, and voice shortcuts. Add apps to the Muted Apps list to pause expansion there. Preferences → General also controls whether Backspace reverses a recent expansion.

Does DevType download updates automatically?

No. Automatic update checks are off by default. If enabled, they check at most once a day and offer a link to the release page. You choose when to download and install a release.

What if dictation or a paste does not finish?

Check the target document before retrying. A paste reported as “posted, unverified” may already have arrived. Voice recovery can retain a recording or transcript when a session is interrupted; a saved transcript alone does not prove it was inserted.

Does it work in VS Code and Cursor?

Yes. Those editors can swallow a synthetic paste, so DevType types the expansion as Unicode keystrokes instead. Other Chromium and Electron apps use the normal paste route. If an expansion fails anywhere, Diagnostics names the refusal and Permission Recovery shows guidance that matches it.

What is Recent Activity?

A menu bar window that lists recent warnings and events, such as permission problems or a kept dictation, with the action that fits each one. You can clear it at any time; that never removes snippets, secrets, or settings.

Why did an AI action say macOS paused it?

On-device models can be deferred by the system under heavy load, usually low memory. Quit apps you are not using and try again. It is a system state, not a problem with your text.

Can I contribute or build it myself?

Yes. DevType is built with Swift and AppKit and released under the MIT license. The contributing guide covers setup, tests, and the contribution workflow; the developer guide explains packaging and signing.
