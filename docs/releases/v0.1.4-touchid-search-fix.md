# DevType v0.1.4 follow-up: Touch ID authentication in secret search

Selecting a secret from **Search Secrets** or the **Copy Snippet** palette previously
failed to prompt for Touch ID and did not copy the password to the clipboard.
Secret selection now reliably presents Touch ID (or password fallback) and copies
the chosen password to the concealed clipboard with automatic expiration.

- Fixes premature `LAContext` invalidation: closing the search palette dismisses
  its window, causing DevType to resign active. `LocalAuthenticationAuthenticator`
  now creates a dedicated `LAContext` per evaluation session so the background
  lifecycle notification does not abort an in-flight authentication prompt.
- Retains the evaluation's `LAContext` across biometric-to-password fallback
  escalation when the user chooses "Use Password…" or biometry locks out.
- Preserves the security model: `BiometricGate` still drops its standing 30-second
  authorization reuse window whenever DevType resigns active (`lastSuccess = nil`),
  so returning to an unlocked Mac requires re-authentication.
- Concealed clipboard markers (`org.nspasteboard.ConcealedType`, `com.agilebits.onepassword`)
  and the 60-second auto-clear timer remain active.

## Security impact

The existing authentication and encryption policies are preserved. Every secret
copy flows through `SecretMenuFlow.resolve`; values remain AES-GCM encrypted in the
local archive and are never read directly from storage without biometric/password
authorization. Cancellation or authentication failure leaves the clipboard
untouched.
