# DevType 1.2.1 — Case-matching expansions, a responsive selection read, and string tables

The GitHub artifact follows the project's existing ad-hoc signed, unnotarized distribution policy. Gatekeeper may reject it. Local packages use the available Apple Development identity.

## Match Trigger Case (sig / Sig / SIG)

- **New snippet option:** case-insensitive snippets gain a **Match Trigger Case** switch in the editor (shown only while Case Sensitive is off). Typing the trigger Capitalized or in ALL CAPS shapes the expansion the same way.
- **Espanso-compatible shape rules:** only the first two letters of the typed trigger are read and non-letters are skipped. Upper+Upper or a lone capital means ALL CAPS, Upper+lower means first letter upper, and anything that starts lowercase (including mixed `sIG`) or has no letter stays as written.
- **Narrower than Espanso, on purpose:** only text written in the snippet template is reshaped. Fill-in values, clipboard text, dates and generated values keep their own case, as do spans an explicit `{{upper:…}}`-style transform already shaped. Cursor markers are remapped when uppercasing changes length (`ß` → `SS`).
- **Importer:** Espanso `propagate_case` matches now import with the option on. The old "output case adaptation is unavailable" note is gone; a new note counts matches that use `uppercase_style: capitalize | capitalize_words`, which DevType imports with the default case shapes.

## Selection reads no longer block the main thread

- **No beachball on AI hotkey, palette, or voice command:** `SelectionReader` ran its whole Accessibility ladder — up to its read budget of synchronous AX IPC, the Chromium settle poll, and the brokered ⌘C wait — on the main thread. Reads now run on a dedicated serial queue and hand their result back on main.
- **Latest press wins:** the AI hotkey, palette AI actions, and the inline search panel only act on the most recent press. A second palette press while the first is still reading closes it instead of queueing a second panel, and a stale read cannot raise a stale alert.
- **AX retries never sleep on main:** focus-query retries and the Chromium accessibility rescue use one bounded policy (`AXSettleRetry`) that waits only off main and reports when a poll was skipped rather than passing it off as zero polls.
- **One focused element per expansion:** an expansion resolves the focused element once and threads it through the entry re-check, IME probe, erase guard, AX writes, delivery check, caret placement and trigger restore, instead of each step re-querying.

## Local Lappi routing (opt-in, off by default)

- **Ask Lappi which tool fits:** when on-device palette routing runs, DevType can also ask a local Lappi agent over a Unix socket on this Mac (300 ms limit). An answer only annotates the routed row as agreeing or differing; it never inserts text or runs anything.
- **Local routing records:** optionally records which tool routing chose and which row you picked, to `Application Support/Lappi/heldout` — the phrase's length and shape, never its text. Records are bounded per day and in total, stay on this Mac, and are never used for training. `LAPPI_COLLECT=0` disables collection.
- Nothing is sent or written while secure input is on. Both switches live in Preferences → AI and default off.

## UI strings move to resource tables

- English, Korean and Japanese UI strings now ship as `.strings` resource tables (`Sources/ExpanderEngine/Localization/Resources/<lang>.lproj/`, eight tables per language) instead of three Swift dictionary literals. `LocalizationManager.swift` drops from 6,254 to 242 lines; every key and value is unchanged.
- The user-chosen UI language still wins over the system language. Malformed tables, missing languages and keys defined twice are reported at load.
- **Pseudolocale for layout checks:** `DEVTYPE_PSEUDOLOCALE=1` (or `-devtype.debug.pseudolocale YES`) accents, brackets and pads every string by about 40%, keeping format specifiers intact.

## Engine internals

- `TextInjectionPipeline` shrinks from 2,688 to 2,024 lines. The undo policy, route-choice policy, entry-gate refusals, swallowed-key and completion-guard types, the image-snippet path and text resolution each move to their own owner; the inject/undo ledger owns its single lock. Unused pass-through members are deleted.
- `ExpanderEngineTests.swift` is split into nine subject files.

---

No dependency, cloud service, permission grant, secret migration, or authentication change is introduced. Existing libraries, secrets, and preferences retain their formats and require no migration. The Lappi socket client is local-only and disabled unless switched on.
