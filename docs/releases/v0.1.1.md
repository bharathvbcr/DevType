# DevType v0.1.1

Release introducing the redesigned **Speech Engine & Correction Subsystem**, decoupling speech recognition (ASR) from transcript correction, establishing crash-safe durable audio capture from frame 0, hardened multi-layer validation with protected span invariance, atomic session persistence (v2 schema), and target lease delivery verification.

## 🎙️ Decoupled Speech Recognition & Correction

- **Independent Capabilities**: Separated voice dictation into independently configurable **Speech Recognition (ASR)** and **Transcript Correction** routes.
- **Provider-Neutral ASR Adapters**:
  - **Apple Speech (On-Device)**: Low-latency offline recognition via `SFSpeechRecognizer` (macOS 14+) with contextual vocabulary injection.
  - **Apple SpeechAnalyzer (macOS 26/27)**: Modern `SpeechAnalyzer` and `SpeechTranscriber` integration.
  - **Local Whisper.cpp Server**: Loopback HTTP adapter (`127.0.0.1`) for local whisper inference.
  - **Gemini Speech**: Cloud speech recognition with strict privacy route verification.
- **Layered Correction & Validation**:
  - **Protected Span Invariance**: Deterministic extraction and strict preservation for URLs, emails, file paths, shell flags, code identifiers, numbers with units, dates/times, currency, versions, and custom dictionary words.
  - **Zero-Latency Deterministic Corrector**: Spoken punctuation mapping, disfluency stripping, sentence capitalization, and false-start self-correction in linear time.
  - **Local HTTP Adapters**: Native support for Ollama (`/api/generate`) and OpenAI-compatible (`/v1/chat/completions`) local servers with anti-hallucination edit ratio guards.
  - **Apple Foundation Models**: Support for macOS 26/27 `SystemLanguageModel` / `LanguageModel`.

## 🛡️ Durable Audio & Session Architecture

- **Durable Audio Capture**: Fixed-capacity lock-free ring buffer pool (`AudioBufferPool`) on the real-time CoreAudio thread with zero heap allocations.
- **Linear PCM Streaming**: Streaming 16kHz Int16 PCM writing directly to `capture.caf` with continuous SHA-256 digest computation.
- **Pure State Reducer**: Actor-backed `VoiceSessionReducer` with generation guards (`SessionTaskBag`) preventing stale callback mutations and late injections.
- **Target Lease Delivery**: `VoiceInsertionService` validates target application PID identity prior to text injection via `TextInjectionPipeline`, preventing misplaced insertions on focus changes.
- **Atomic Persistence & Recovery**: Atomic session directory storage (`~/Library/Application Support/DevType/VoiceSessions/<UUID>/`) with launch crash recovery.

## 🧪 Quality & Tests

- **1,439 tests executed with 0 failures** (1,432 passed; 7 opt-in live-AI tests skipped).
- **Stable progressive typing**: live speech revisions now pass through a single transcript
  reconciler with committed-prefix barriers, preventing pauses, endpoint punctuation, or
  late recognition revisions from destructively replaying text already inserted.
- **Pause-safe utterance handoff**: finalized text from a superseded speech utterance is sealed
  before the replacement stream starts, preserving words across pauses and late callbacks.
- **Stock Whisper server support**: local setup discovers the Homebrew binary, emits a valid
  launch command, probes the server's request-path root, and converts captured audio to WAV
  before multipart inference.
- **Bounded Foundation Models correction**: oversized transcripts are divided into fresh
  correction sessions within the shared context-window budget, while protected spans remain
  invariant across chunk boundaries.
- **Bounded session lifecycle**: generation guards, stage watchdogs, privacy-route checks,
  atomic recovery, and a single delivery owner replace the overlapping legacy dictation paths.
- **Preferences layout regression fixed**: the embedded Home scroll view now participates in
  the same constraint system as the other settings panes, so switching to Advanced (or any
  other tab) keeps its controls visible.
- **AI preview crash fixed**: word and character delta labels now pass integer values through
  integer format specifiers instead of treating them as Objective-C object pointers.
