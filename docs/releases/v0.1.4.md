# DevType v0.1.4

DevType v0.1.4 improves text expansion in editors that report inconsistent cursor positions,
and makes secret search easier to use during password entry.

## Expansion recovery and safety

- Fixed the refusal where an editor reports cursor position zero in a nonempty field, such as
  `caret 0 leaves no room for a 4-unit erase in a 44-unit field`. Zero and near-zero positions
  now use the existing recovery path when a bounded scan finds the expected trigger and no
  selection is reported.
- Recovery uses keyboard deletion and clipboard paste instead of writing through the
  unverified Accessibility range. A missing trigger still refuses expansion.
- Input or application changes observed during the erase check cancel the operation. A
  cancelled operation does not replay its swallowed key into a changed target.
- Undo remains strict, and an unverified prior Accessibility write cannot trigger a second
  erase and insertion.
- Case-insensitive searches apply Unicode case folding after selecting the bounded text
  window, preserving cursor offsets when lowercasing changes the text length.
- Refusal diagnostics include cursor position, selection length, field length, trigger-presence
  evidence, and whether the scan covered the full field or only a cursor window. The original
  expansion gate is retained for the initial erase refusal.

## Password-field & Search Secrets experience

- **Direct Search Secrets**: Primary-clicking the menu bar button while Secure Input is active opens the **Search Secrets**
  palette directly with the search field focused. Right-clicking or Control-clicking opens the full status menu.
- **Single-click selection**: Choosing a secret in the search palette commits the clicked row with a single click.
- **Touch ID prompt reliability**: Fixed premature `LAContext` invalidation where closing the search palette caused DevType
  to resign active and abort the in-flight Touch ID evaluation. Each evaluation session now uses a dedicated `LAContext`.
- **Keyboard navigation**: Arrow keys navigate, Return and `⌘1`–`⌘9` jump shortcuts commit the selected secret.
- **Stability & status retention**: Focus changes, snippet edits, and preference changes cannot rearrange rows under the
  pointer while the menu is tracking; closing the menu restores current engine status.
- **Localized guidance**: Updated guidance in English, Korean, and Japanese, including VoiceOver accessibility labels.

Secret copies continue through the authenticated secret-copy flow. Typed secret triggers and
ordinary text expansion inside secure fields remain suppressed by design.

## Verification

- The zero-cursor regression was reproduced against the original implementation before the fix.
- `./Scripts/test.sh`: **1,950 tests total; 1,936 passed, 14 skipped, 0 failures**. The skipped
  tests require opt-in for live AI or native window interaction.
- Coverage includes Unicode and whitespace variants, every cursor position before the trigger
  width, selections, oversized fields, input/focus cancellation, undo, and duplicate-insertion guards.
- The release configuration compiles successfully.
- The reported Claude editor interaction has not yet been verified through live typing. Unit
  and contract tests establish the recovery policy, not delivery in a third-party editor.

## Local build and distribution status

Local installation uses the existing **Apple Development** signing identity and remains
**unnotarized**. The packager stamps `CFBundleShortVersionString: 0.1.4` from the local
`v0.1.4` tag and derives the build number from the commit count. The previous unpublished tag
object is retained under an archive ref when assigning this local release name to the fix.

The installation target is `/Applications/DevType.app`. Local installation does not publish a
GitHub release or establish Gatekeeper/notarization approval.
