# DevType v0.1.4

DevType v0.1.4 introduces the **Merge & Rewrite** on-device AI transform, selection-aware
suggestion ranking in the Command Palette, unified multi-word tokenized search across all panels,
keystroke performance bounds and timeout safety, guarded caret recovery in non-standard editors,
and direct single-click secret search in password fields.

## Merge & Rewrite AI transform

- **Fragment deduplication**: Added the **Merge & Rewrite** (`ai.mergeRewrite`) on-device transform
  to fold overlapping fragments, scattered notes, or resume bullets into a single coherent passage.
- **Metric & structure preservation**: Prompt engineering explicitly preserves numbers, metrics,
  tools, names, dates, outcomes, and list formatting without summarizing away vital details.
- **Contract & bounds**: Uses a dedicated token budget (0.7) and enforces strict chunk refusal for
  non-chunk-safe merging (refusing oversized input rather than silently splitting).
- **Collision-free vocabulary**: Strengthened alias matching with `minimumDiscriminatingTermScore` (800)
  at word boundaries so multi-word aliases do not collide with short substring keywords.
- **Catalog & templates**: Integrated `:mr` default snippet trigger, Markdown policy classification,
  and localization in English, Korean, and Japanese.

## Selection-aware Command Palette & dynamic section leading

- **Context-driven suggestions**: The empty Command Palette (`⌘/`) inspects whether text was selected
  when opened. When a selection is present, AI transforms and local text operations lead over navigation,
  surfacing perishable actions above the fold.
- **Dynamic section ordering**: Sections are ordered by their highest-scoring match instead of a static
  commands/AI/snippets sequence. A high-scoring AI transform or snippet surfaces immediately above commands.
- **Deterministic tie-breaking**: Section ties preserve canonical ordering, preventing list jitter between
  keystrokes. When AI is unavailable, local text operations lead seamlessly.

## Unified multi-word tokenized search

- **Canonical snippet scoring**: Replaced duplicate search logic in the Snippet Manager with
  `SnippetSearch.score`, unifying search across triggers, labels, tags, and content.
- **Shared TokenizedFilter**: Adopted `TokenizedFilter` in the AI Action Panel and Shortcut Reference
  Window, ensuring multi-word queries match conjunctively across all item fields.
- **Cross-field matching**: Multi-word queries like `sig email` or `cmd palette` consistently match
  items across distinct metadata fields without requiring words to be adjacent.

## Keystroke performance bounds & routing timeouts

- **Keystroke query ceilings**: Keystroke search paths now enforce `maximumQueryCharacters` (512) and
  `maximumQueryTerms` (12) across `CommandPaletteCatalog`, `SnippetSearch`, and `TokenizedFilter`,
  eliminating multi-second UI freezes during large clipboard pastes.
- **Palette router timeout**: `PaletteToolRouter.route` enforces an 8-second deadline with active task
  cancellation and single-flight latch recovery, ensuring unresponsive models cannot wedge palette routing.

## Guarded caret & expansion recovery

- **Zero-cursor recovery**: Fixed expansion refusal where editors report cursor position zero in non-empty
  fields. Zero and near-zero positions now recover through keyboard deletion and paste when a bounded scan
  verifies the trigger without a selection.
- **Cancellation & safety**: Input or application changes during the erase check cancel the operation without
  replaying swallowed keys into changed targets. Undo remains strict against duplicate insertions.
- **Unicode folding**: Case-insensitive searches apply Unicode case folding after selecting bounded windows,
  preserving cursor offsets across variable-width character changes.

## Password-field & Search Secrets experience

- **Direct Search Secrets**: Primary-clicking the menu bar button while Secure Input is active opens the
  **Search Secrets** palette directly with the search field focused. Right-click or Control-click opens
  the full status menu.
- **Single-click selection**: Choosing a secret in the search palette commits the clicked row with a single click.
- **Dedicated Touch ID context**: Each evaluation session uses an independent `LAContext`, preventing app
  resignation from prematurely cancelling in-flight biometric checks.
- **Keyboard navigation**: Full arrow-key navigation, Return to commit, and `⌘1`–`⌘9` jump shortcuts.
