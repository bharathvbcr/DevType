# DevType v0.1.4 follow-up: direct secret search

Clicking **Copy Secret** in the menu bar now opens **Search Secrets** directly,
with the search field focused. Choose a result, authenticate when required,
and paste with **⌘V** in the password field.

- Right-click or Control-click the status button for the full DevType menu.
  Ordinary primary clicks still open that menu when Secure Input is inactive.
- An explicit search request replaces an already-open palette and releases its
  previous matching suspension and dismissal observers.
- Secret-only search excludes commands even for `>` queries or late AI answers.
  Zero or negative command limits now return no commands without crashing.
- Programmatic button presses cannot replay an already-handled secondary click.
- Deferred menu rebuilds run after native tracking returns, outside AppKit's
  menu open/close callbacks. The obsolete submenu-promotion path is removed.
- English, Korean, and Japanese guidance explains the direct click and full-menu
  access. Accessibility identifies the contextual action as a button.

## Security impact

Opening search displays library metadata and does not resolve secret values.
Selecting a result retains the existing `SecretMenuFlow` authentication,
concealed clipboard, and expiration policy. Typed expansion remains blocked
in secure fields. Secret-only queries no longer schedule command AI routing.
No permissions, authentication policies, or encryption settings are widened.

## Verification

Regression checks reproduced the old menu-only wiring, command-filter bypass,
negative-limit crash, and stale secondary-click replay before their fixes.
Native AppKit checks use synthetic data to verify focused search, palette
replacement, empty results, selection callbacks, suspension cleanup, and
primary/secondary/Control-click delivery through a real status-bar button.

- Full suite with native AppKit checks enabled: **1,931 tests, 0 failures,
  7 opt-in live-AI skips**.
- Focused search, status-button, and source-contract checks: **86 passed**.
- Existing presentation coverage retains 1,024 state combinations and 10,000
  focus transitions; click routing adds 2,000 alternating activations.
- Relative documentation links: **35 verified**.
- Local CI passed, including release-script self-tests, debug/release builds,
  packaging, bundle identity/version checks, and signature verification.

The original [v0.1.4 release notes](v0.1.4.md) describe the tagged build. This
follow-up retains that tag and uses the package script's commit suffix and
incremented build number so the installed app identifies its exact source.
Local Apple Development signing does not provide notarization or Gatekeeper
approval. Third-party password fields and physical Touch ID remain manual
verification surfaces; synthetic UI checks do not certify every application.
